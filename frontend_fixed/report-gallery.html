每一份报告都是对单个虚拟实验场景的验证与确认（V&V）文档，结构对齐 ASME V&V 10-2019 与 FDA 计算模型与仿真（CM&S）报告大纲。报告由确定性离线计算生成（无 LLM 参与）， 对照场景自带的解析解 / 发表基准函数——这正是把"一串数值"变成"一份可归档的厚报告"的交付物。 用于真实决策前，仍需按 mirror-run 做一次对等度验收。

判定口径（单侧下界，诚实 UQ）：PASS = out-of-sample R² ≥ 0.90 且 95% 区间覆盖率 ≥ 0.90； MARGINAL = R² ≥ 0.70 且覆盖率 ≥ 0.80；其余判 REFUTED（拟合不足或过度自信）。 覆盖率高于名义值属保守安全，不罚分。
UQ κ（方差标定系数）：GP 预测区间经 κ 倍经验加宽后，才在独立验证集上达到名义 95% 覆盖。 κ = 1.0 表示区间本就诚实；κ > 1 表示该场景 GP 原区间过度自信，已按"宁可保守不可过度自信"原则加宽， 该放大系数如实写进每份报告（诚实 UQ，绝不隐瞒）。
数据来源：engine/report_generator.py · 同源代码 engine/surrogate.py :: SurrogateEngine（GP + UQ）。 完整清单 API：GET /v3/reports · 单报告：GET /reports/json/{key}.json / GET /reports/html/{key}.html / GET /reports/docx/{key}.docx。
每张卡片可在线查看 10 章 HTML 报告，或下载 .docx 归档版（一份可直发的"厚报告"，含 Reproducibility Manifest）。
验证类型标签由 engine/scenario_trust_labels.py 统一生成：闭式解析解 / 发表基准 / 湿实验锚定 / 合成代理。 禁止场景（forbidden use）由同一模块生成——展开卡片下方的「▸ 适用 / 禁止场景」可看。

诚实边界（适用边界，不隐藏）：上方 91 PASS, 3 MARGINAL, 1 REFUTED 是样本内口径。更严苛的留压测试下，诚实失败会更多—— 外推压力测试：95 个场景中有 73 个落在 REFUTED 区间（模型在训练域外失效，这正是诚实 UQ 要暴露的适用边界）； 鲁棒性留出集：95 个场景中有 10 个被判 REFUTED。这些"失败"不是缺陷，而是"哪里可信、哪里会失效"判定报告的一部分。 SwarmLabs 卖的不是"万能预测"，而是可归档的适用边界。原始计数见 data/heldout_index.json 与 data/public_facts.json。
