Agentic-Science Agent ↔ SwarmLabs Trust Gate 的无网络通信模式

架构概述

Agentic-Science Agent 不直接调用 HTTPS API，而是将预测写入 bus/inbox/ 目录。 SwarmLabs 信任闸门进程监听该目录，消费预测后调用真实验证 API，将 verdict 回写到 bus/outbox/ 目录。 Agent 读取 verdict 文件后的退出码决定后续行为：

退出码状态语义
0PROCEED验证通过，可以继续
2BLOCK验证失败，禁止自主动作
3HUMAN_CHECK需要人工签字
4UNREACHABLE无法到达裁决者（网络失败）
1ERROR调用/参数错误
运行演示

点击按钮执行模拟演示。演示使用真实 SwarmLabs 验证 API，但预测数据由脚本生成：

目录结构
bus/ ├── inbox/ # agent 写入预测文件（*.json） │ └── bio_logistic_predictions.json ├── outbox/ # gate 回写 verdict 文件 │ └── bio_logistic_verdict.json └── logs/ # 执行日志 └── demo_*.log 文件内容示例： { "scenario_key": "bio_logistic", "predictions": [ {"x": [0.1], "y_pred": 0.35, "y_std": 0.05} ], "agent_name": "agentic-science-demo", "timestamp": 1793264164.0 } Verdict 文件示例： { "scenario_key": "bio_logistic", "exit_code": 0, "gate": "PROCEED", "status": "PROCEED", "message": "验证通过，可以继续", "timestamp": 1793264164.5 }
使用方式
# 1. 演示两种典型场景 python demo_file_as_bus.py --demo-proceed python demo_file_as_bus.py --demo-block # 2. 使用真实场景和预测文件 python demo_file_as_bus.py \ --scenario bio_logistic \ --predictions my_predictions.json # 3. 清理演示产生的文件 python demo_file_as_bus.py --clean # 4. 直接使用 vv_gate 验证单个预测文件 python engine-kit/skills/vv-gate/scripts/vv_gate.py verify \ --base https://swarmlabs.tools \ --key bio_logistic \ --pred my_predictions.json
离线模式说明

在无网络环境中，可信硬件代理可以本地缓存最近一次公开的验证报告作为 本地裁决者。 验证闸门消费预测时，若无网络访问能力，会返回退出码 4 (UNREACHABLE)， 调用方应在此时触发人工评估流程，禁止 agent 继续执行潜在有害操作。
