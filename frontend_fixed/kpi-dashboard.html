KPI Dashboard · 18 项可度量指标

Phase 1 交付的诚实度量框架。18 项 KPI 覆盖 科学质量 · 产品体验 · 业务转化，每项都有明确 target、baseline、data_source 和 status。2 项 meeting / 16 项 unmeasurable —— unmeasurable 不是"没做"，是"需真实用户数据或前瞻实验"的显式边界标注。

⚠️ 为什么要显式标注 unmeasurable

报告 §7 的原话：「Replace scenario-count vanity metrics with measurable science/product/business KPIs.」过去"95 场景 / 91-3-1-0 判决 / 10 学科"是交付量指标，不是科学质量指标。KPI registry 强制每一项声明"当前是否可测量"—— unmeasurable 有 16 项不是失败，是让"当前可测"与"接入真实数据后可测"的边界显式化。

Science批次留出误差
kpi-sci-batch-holdout
完全未见过的 batch_id 上的预先指定主指标。检验模型是否只对训练批次过拟合。
mean(|y_hat - y_true| / range(y)) over held-out batches
阻断：至少一组 E2/E3 真实批次数据 + 预登记 batch_id split
 ≤ 5.0 % — 待接入 🟡 Unmeasurable
Science区间有效性
kpi-sci-interval-validity
PICP/coverage 达预登记目标；宽度也须报告，避免 vacuous interval。
coverage = mean(y_true ∈ [q_lo, q_hi]); width = mean(q_hi - q_lo) / range(y)
阻断：真实前瞻实验的覆盖率测量（合成场景已达 0.95，但非真实数据）
 ≥ 0.95 0.95（合成） 🟡 Unmeasurable
ScienceOOD 安全性
kpi-sci-ood-safety
proximity() 过滤后 OOD 检出率与误拒率同时报告；selective risk 是拒答条件下的风险上界。
阻断：真实前瞻 OOD 套件 + 在分布集对偶标签
 检出 ≥ 0.90 / 误拒 ≤ 0.05 — 待接入 🟡 Unmeasurable
Science建议兑现率
kpi-sci-fulfillment-rate
真实实验完成后兑现的建议比例。诚实分母：排除未量化和等待执行的建议。
阻断：真实实验执行反馈（scripts/fulfillment_replay.py 已实现诚实分母口径）
 ≥ 0.40 — 待接入 🟡 Unmeasurable
Science信息增益 / 成本
kpi-sci-info-gain-cost
Expected Improvement / 实验成本。主动学习每步的信息增益与实验花费之比。
阻断：真实实验成本数据（当前无成本标签）
 越高越好 — 待接入 🟡 Unmeasurable
Science负对照识别
kpi-sci-negative-control
零函数/常数函数等负对照在系统输出中应被识别为 REFUTED（不可用）。当前 fin_put_call_parity 已作 selftest。
阻断：需前瞻负对照套件（真实数据）验证

第二后端/团队/设备对同一 manifest 的复现率。SLSA v1.2 provenance 已就绪，缺"另一后端"验证。
阻断：Phase 2 Second Backend 骨架 + 外部团队 pilot
