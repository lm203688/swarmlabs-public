SwarmLabs 的诚实 V&V 定位恰好踩中 AI4S 从 demo 跨越到 instrument 的临界点。

Trust is the bottleneck（Heimdall 2026）

含义：SwarmLabs 在正确赛道，且卡位正当时。

Evaluations caught up

含义：SwarmLabs 的品类从"被时代甩在身后"变为"时代刚需"。

3. 六项可落地提升战略

S1 · 定位升维

Benchmark → Trust Layer / Evaluation Instrument
全站叙事从"基准测试集"改为"AI4S 可信验证层 / 科研仪器的验证闸门"。保留"不做跨学科通用验证"红线——把 G3=0、73/95 REFUTED 当荣誉徽章。
落地：重写 index hero / llms.txt 首段 / mission；本页作定位层入口。

S2 · 诚实即护城河

Honesty as Moat
将"诚实失败"从被动披露升级为主动产品——"Trust Surface"成为可售卖的核心差异化能力。在竞品普遍报喜不报忧时，诚实不可复制。
落地：trust-dashboard.html 升级为 Trust Surface Product，演示 calibrated coverage + 适用域边界 + OOD 自动阻断。

S3 · 验证即服务

Verification-as-a-Service
把 engine/ 验证内核包装为 MCP server + A2A agent（agent-card 已就位，需生产化：JWS 签名、capabilities、健康检查），暴露 verify_claim / rank_next_experiments / proximity_check。
落地：engine/mcp_server.py + SKILL.md，让 K-Dense 科学 agent 一键调用。

S4 · 嵌入生态

Plug into the Agentic Stack
发布"SwarmLabs as the trust gate for agentic science"定位与 File-as-Bus 对接 demo。从"自建闭环"转为"成为别人闭环的必要一环"——零获客成本卡位生态。
落地：最小可运行 demo（agent → SwarmLabs verify → fail-closed 阻断）。

S5 · 补齐硬阻塞

De-risk
CI 账户级红（需用户侧 billing 或转公开仓）；清退五处 UNSOURCED 声称（143/900k+）；138 pending 改为"诚实待实现"标识而非硬补数量。
落地：本地门禁全绿 + 手动部署；index/lab/login/pricing/terms 改用 engine_modules / store_points_total。

S6 · 竞赛 / 资助

Pipeline
维护 grants-radar（已 12 项）+ 竞赛追踪；纳入 Chen Prize / EOSA / ICLR Workshop 状态。投稿 / 申报 / 签名 / 出席须用户本人。
落地：grants-radar 新增 3–5 个 2026-2027 可投竞赛条目。
