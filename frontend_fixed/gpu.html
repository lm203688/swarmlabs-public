⚡ WebGPU Inference

Browser-side AI4S surrogate inference. Two modes: GP kernel demo (Matérn/RBF) or 10 real trained MLP checkpoints loaded from data/small_models. Automatic CPU fallback.

Real model data: data/small_models/*.npz holds 10 MLP surrogates trained on SwarmLabs scenarios (Forrester/Branin/Hartmann6 + bio/chem/ML/physics). Each checkpoint is ~2KB JSON with float32 weights — loaded live, no server roundtrip. Forward pass runs entirely on WebGPU compute shader.
