Pilot Reference · 真实数据 Pilot 参考实现

Phase 1 报告 §11 硬门槛：「没有真实数据 pilot，只能称'格式兼容'，不能称'真实实验验证'」。本页把"接入真实数据"这个门槛拆成纯配置工作——CLI 已跑通 CSV→BatchRecord→batch_id 隔离→holdout 评估→RO-Crate 1.1 导出→PilotReport 全流程。要跑真实数据，只需把 --input 换成真实 CSV。

🔴 当前状态 · verdict = needs_data

合成数据（8 批次 / 56 观测点）跑通全流程，但 RMSE_rel = 0.44 / Coverage = 1.00。原因：poly3 拟合不了 sigmoidal 生物量生长曲线。这不是缺陷——正说明这是"参考骨架"而非"生产级模型"。换成真实数据 + 换代理模型（engine/surrogate.py GP）即可。诚实标注边界，比虚假达标重要。

🚀 跑合成数据（默认）

# 默认跑 data/pilot_reference/synthetic_batch.csv
# 8 批次 / 56 观测点 / evidence_grade=development_demo

🧪 换真实数据

# 把 --input 换成真实 CSV 即可
python scripts/pilot_reference.py \
  --input /path/to/real/batch_biomass.csv \
  --evidence-grade retrospective \
  --output-dir outputs/pilot_real_001 \
  --pilot-id REAL-001

列名说明

media_lot培养基批次（可选，映射到 materials）
ph / do_pct / temperature_c / glucose_g_l / iptg_mm过程变量（可选，自动收进 variables）

⚠️ 诚实边界

这不是"生产级" pilot。它证明的是骨架：CSV→BatchRecord→batch_id 隔离→评估→RO-Crate 全流程能跑通，且每一步都有可审计的产物。要升级为生产级 pilot 需要：

1️⃣ 真实数据（evidence_grade=retrospective 或 prospective）
2️⃣ 更合适的代理（engine/surrogate.py GP / FNO，不是 poly3）
3️⃣ 足够批次（≥ 10 训练 + ≥ 3 校准 + ≥ 2 测试）
4️⃣ 预登记 batch_id split（在见到测试数据前锁定划分）
