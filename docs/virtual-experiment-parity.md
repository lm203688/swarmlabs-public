# 虚拟实验对等现实 —— 战略与路线

> 用户原话："对于核心的虚拟实验部分，我想你持续的关注此领域的技术，我想把这部分做到可以和现实实验一样的程度……其实现实中也是一个编码世界，我们只是某种程度减少了干扰因素，用数学和演算加快过程。另外多关注竞品，不要被拉下。需要算力的可以先搭好框架，作为融资或者以后算力充足的时候再上规模。"

## 1. 核心哲学（已采纳为顶层原则）
- **现实 = 编码世界**：物理规律是微分方程，随机动力学是噪声+采样。虚拟实验不是"近似现实"，而是把现实里不得不承受的干扰项主动削减、用可微数学加速收敛。
- 因此"虚拟实验达到现实实验程度"不是口号，而是工程目标：**在误差棒可比、校准良好的前提下，用虚拟替代可替代的真实**。
- **UQ 一等公民**：没有不确定性量化的"虚拟实验"不可信；误差棒是它"像真实实验"的硬指标。

## 2. 技术前沿（2026-08 调研，必须持续跟踪）
### 2.1 科学智能体（直接竞品/标杆）
- **Google DeepMind Co-Scientist**（Nature 2026, Gemini 2.0）：通用多智能体，"idea tournament"自检；为急性髓系白血病提候选药，湿实验验证 5 选 3。
- **FutureHouse Robin**（已开源，o4-mini+Claude 3.7）：假设→实验设计→结果解读半自主闭环；干性 AMD 案例把"可实验"时间从 >300h 压到 <2h。局限：还不能生成可直接执行的实验协议，Finch 子代理需专家精确提示。
- **Biomni**（Stanford）：agentic biology，把专家知识民主化——印证"降本增效"是主航道。
- **DeerFlow 2.0**（字节，MIT，GitHub Trending #1）：调研→产出 SuperAgent 编排（沙箱/子代理/记忆/MCP）。不是科学闭环，但证明"长链路编排"范式已被市场接受。

### 2.2 物理信息 / 数字孪生 / UQ（技术基石）
- **DD-PINNs 数字孪生**（ScienceDirect 2024）：多保真度 + 集成 UQ，较单保真度提升 42~62%。
- **FIM 引导 PINN**（2025）：Fisher 信息矩阵做实时参数辨识 + UQ 置信区间，非线性振系验证。
- **VDMN 变分深度材料网络**（npj Comput Mater 2026）：物理+微结构感知代理，正/逆概率预测，实验验证。
- **主动学习数字孪生**（arXiv:2605.06756, INL）：Modelica 仿真耦合 SINDyC/FNN/GRU 代理，
  **主动学习用 1/5 仿真轨迹达到同等精度**——这是 SwarmLabs 飞轮的强学术背书，必须对标。

## 3. SwarmLabs 差异点（不要被拉下的理由）
竞品多在"**提实验让人做**"（LLM 编排文献+湿实验），我们做"**仿真+UQ+挑最该做的真实实验**"——
虚拟层本身可独立达标，真实实验是校准锚点而非瓶颈。这套"虚拟→真实对等闭环"目前是空白带。

## 4. 已落地框架（scripts/virtual_experiment/）
- `parity_framework.py`：GP 代理(UQ) + 主动学习 + 校准器 + `run_parity_loop` 闭环（自测收敛）。
- `fidelity_ladder.py`：GP→PIML→神经算子→校准数字孪生 四级阶梯，标注算力就绪度。
- 算力重的 **NeuralOperatorSurrogate / RemoteLabOracle** 留接口与桩，框架就绪。

## 5. 路线（框架优先，规模在后）
1. **现在**：GP 代理 + 主动学习闭环（CPU 即可），跑通自测，作为方法成立的证据。
2. **融资/算力到位**：启用 PINN/神经算子（单卡→多卡），接 RemoteLab/HPC 做真实校准。
3. **持续**：周级竞品/技术监测自动化（见 competitor_watch.py），不落后。

## 6. 诚实边界
- 当前框架用 SyntheticOracle 自测闭环成立，但**尚未对接真实实验设备/HPC**（桩）。
- "对等现实"是工程目标，需真实数据持续校准才能兑现，非一次部署可达。
- 竞品（Co-Scientist/Robin）有 Nature 级背书与真实湿实验验证，我们需在"虚拟层可信度+省真实实验"上建立可量化优势。
