## 四、诚实边界
1. 国内免费 GPU 多为 **V100/A100 每日限时**（非 NVIDIA Inception 的 H100 量级、非长期独占），适合**原型验证与小批量**，不适合大规模训练。
2. 竞赛类需**获奖**才拿算力/现金，非稳得。
3. 任何"免费"政策随时变，动手前以官网最新公告为准。
4. 用户头衔（教授级高工 / 外籍院士）在 Tier1/2 **完全用不上**（本来就对个人开放）；价值在 Tier3 关系撬动与对外 credibility。
