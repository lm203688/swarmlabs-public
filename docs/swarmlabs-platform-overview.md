## 2. 它解决什么痛点（真实实验的硬约束）

真实实验被**物理世界束缚**——时间、空间、设备、成本、可覆盖的工况数都有限。虚拟实验只被**算力与数据边界**束缚，而这两者能随自治飞轮持续扩展。

| 真实实验的约束 | SwarmLabs 虚拟实验 |
|---|---|
| **时间**：一次实验数小时~数天，还要排队等机时 | **即时**：工况输入即得结果，无等待 |
| **空间**：必须到物理实验室、用专用设备 | **无地点限制**：本地 / 云端 / 笔记本即可跑 |
| **成本**：耗材、机时、人力昂贵 | **近零边际成本**：跑一次≈一次计算 |
| **覆盖**：只能测有限工况，海量组合测不起 | **全空间可探**：任意工况即时预测 |
| **不确定不可知**：测了也不知道「漏了什么区」 | **UQ 一等公民**：每结果带可信区间，知道边界 |

## 3. 核心能力 / 功能模块（功能 + 用法）

### 3.1 概率代理建模（Surrogate）— 替代实验的「黑箱测量」
- **功能**：给定少量 `(工况 → 结果)`，模型学会映射，对任意未测工况给出**预测值 + 误差棒**。
- **用法**：`engine.SurrogateEngine.fit(X, y)` 后 `predict(x)` 返回 `(均值, 标准差)`。
- **价值点**：在某真实电厂数据集上，仅用 **250/9568** 记录即把其余工况预测误差控制在 ~26%（注：此处真实记录用于**证明对等度**，非前置依赖——虚拟实验本身不需要它们）。

### 3.2 UQ 误差棒校准 — 让「替代」可信
- **功能**：误差棒不是装饰——平台用**自研噪声标定机制**将 95% 置信区间校准到真实覆盖 ≈95%，覆盖不足会显式标注（不粉饰）。
- **用法**：默认开启；`predict` 返回的 σ 即校准后的不确定度。
- **价值点**：这是能「放心替代真实实验」的基石——你清楚每个虚拟结果的可信边界，而非拿到一个无依据的标量。

### 3.3 主动学习「实验锦标赛」— 替代实验员的「决定测什么」
- **功能**：对候选工况按**信息增益 / 不确定性**排名，自动覆盖信息量最大的区域。
- **用法**：`engine.suggest_next_experiments()` 返回排名后的候选点清单。
- **价值点**：在虚拟空间内自动扩展覆盖，**无需人肉决定测哪些点、无需真实机时**——探索本身也不受时空限制。

### 3.4 物理信息神经网络（PINN）— 用方程替代「需要数据才能学」
- **功能**：对带明确偏微分方程的场景，无需海量数据，用 PDE + 边界条件在 CPU 上学出场解。
- **用法**：定义方程残差，`fit` 后 `predict` 即得解场。
- **价值点**：1D 边值问题学出的解与解析解 RMSE 达 1e-5 量级，**零 GPU、纯 CPU**。

### 3.5 神经算子 — 学「从一种条件到另一种场」的映射
- **功能**：把算子本身（如「初值场 → 某时刻场」）作为学习对象，一次训练后可对任意新初值即时推断。
- **用法**：`DeepONetSurrogate.fit(u0_grid, uT_grid)` 后 `predict(new_u0)`。
- **价值点**：黏性 Burgers 算子学习测试 RMSE ~0.19、覆盖 ~0.94，**CPU 训练约 3 秒**，纯 numpy 实现无外部依赖。

### 3.6 RemoteLab 闭环 — 统一后端（接仿真 / 已发表数据校准）
- **功能**：把「提交实验 → 取回结果」抽象成统一后端，可接仿真、已发表数据集或（可选）真实实验台。
- **用法**：`RemoteLabOracle(data=(X,y))` 或 `endpoint=...`，`observe(x)` 返回结果值。
- **价值点**：虚拟闭环自洽运行；接真实已发表数据集验证回读 RMSE=0.0，意味着「取回即真实值」，可直接并入飞轮做校准。

### 3.7 多 Agent 可信协作（组织级能力）
- **功能**：以「设计基点 + 职能 Agent + 可复用 Skill」组织科研闭环，含**权限边界、审批闸门、双流审计**（Trace + Audit），保证每一步可回溯、可问责。
- **用法**：通过统一编排入口提交任务，关键写操作需显式审批。
- **价值点**：满足「可信执行 / 多 Agent 协作 / 知识累积」类赛事与企业的合规要求，且全程不受物理协作空间限制。

### 3.8 知识累积飞轮 — 越用越强
- **功能**：每次虚拟实验 / 校准回填后，代理、噪声标定、主动学习策略同步更新；日级自治运行。
- **用法**：平台自动跑日级闭环，无需人工值守。
- **价值点**：数据资产形成复利，而非一次性消耗；自治意味着它不依赖任何人的在场时间。

## 9. 技术脱敏声明（防抄袭）

本文**刻意不公开**以下核心实现，以保护方法壁垒：

- 概率代理的**自适应归一化与多尺度核学习**具体实现（避免高幅值平台区欠拟合的关键）；
- 误差棒的**自研噪声标定机制**（如何从少量真实点反推可信噪声地板，使覆盖≈95% 而不人为收窄）；
- 主动学习**候选点排名与守卫策略**（避免外推退化的数据量门槛与交叉验证选参）；
- PINN / 神经算子的**训练稳定性与轻量化实现细节**（纯 CPU 跑通的工程诀窍）；
- 多 Agent 编排的**授权矩阵与双流审计**具体契约。

这些「know-how」是平台「替代真实实验且可信」的来源，对外仅以**能力 + 对等度验证结果**呈现。如需技术尽调，可走 NDA 下的定向沟通。
