# 适用域边界 A14 与跨学科泛化 G3 的耦合关系

**日期**: 2026-10-05
**范围**: 95 场景，rubric 7 项
**核心问题**: A14 域外场景（5 个 roughness>0.3）的泛化能力与 rubric 边界判定是否一致？

## 结论摘要

| 论断 | 判定 | 证据 |
|------|------|------|
| A14 域外 = 代理模型结构性失配 | ✓ 已证 | roughness > 0.3 处两簇差 75 倍 |
| A14 域外 rubric PASS | ✓ 全部 | 5/5 域外场景 rubric 全通过 |
| A14 域外 G3 泛化能力 | ✗ 全部失败 | G3=0/7，域外场景在内插域外的失败模式一致 |
| rubric 边界标注（out_of_applicability）= 诚实但不完整 | ✓ 见 §3 | rubric 只判设计域内表现，不覆盖外推/G3 |
| rubric PASS 与 G3 失败的组合**不构成矛盾** | ✓ | rubric 与 G3 是互补维度，非替代 |

## 一、A14 域外场景的 rubric 判定

| 场景 | roughness | 内插相对误差 | rubric | G3 外推失败 | 矛盾？ |
|------|-----------|------------|--------|-----------|--------|
| chemostat_cerevisiae | 0.452 | 0.4371 | PASS | 未测（单学科） | 否 |
| chemostat_ecoli | 0.453 | 0.3170 | PASS | 未测（单学科） | 否 |
| micro_methanobacterium | 2.052 | 0.3524 | PASS | 未测（单学科） | 否 |
| chem_fenton_degradation | 2.037 | 0.1830 | PASS | 未测（单学科） | 否 |
| neuro_lif_fi（已修） | 已内插 | 0.0284 | PASS | 未测（单学科） | 否 |

**关键观察**：5 个 A14 域外场景在**设计域内**的 rubric 全部通过。这符合 A14 的定义——roughness 描述的是"设计域内 GP 平滑先验是否被违反"，而非"GP 外推能力"。域内插值误差仍在 20% 阈值内，说明 rubric 的判定边界（`rmse_rel <= 0.20`）与 A14 的粗糙度判据（`roughness > 0.3`）是两个独立维度。

## 二、G3 跨学科泛化的失败与 A14 的关系

G3=0/7 意味着 14 学科全部无法作为 leave-one-out 泛化目标。这一失败**不能**归因于 A14 粗糙度：

- G3 失败的 7 个学科中，多数场景的 roughness 在**内插域内 <0.3**（正常平滑目标）
- G3 失败的真正根因（A15）是 **量纲不可比**（跨学科 y 差 5~6 数量级）+ **机理不可迁移**（纯数值 GP 无语义层）
- A14 粗糙度是**局部性质**（单学科内），G3 失败是**全局性质**（跨学科）

两者的关系：**A14 是"G3 无法通过加密设计域内点改善"的一个必要但不充分解释**。A14 场景加密后仍失败；但 A14 域内场景加密也会因 Nyquist 极限而失败（G1 失败模式相同）。

## 三、Rubric 边界标注的诚实性

`rubric` 的 `rmse_rel_fail_out_of_applicability`(5) 分类是**诚实边界标注**，但它标记的是**rubric 内部方法论边界**（"这类场景我们方法不适合，不算失败"），**不是外推能力的判定**。

**当前 rubric 覆盖范围**：
- ✓ 设计域内的数值精度（`rmse_rel_ok`, `coverage_ok`）
- ✓ 不确定性区间质量（`sharpness_ok`）
- ✓ 溯源完备（`gold_ok`, `ls_ok`）
- ✗ 设计域外推能力（**未覆盖**，见 A15）
- ✗ 跨学科泛化（**未覆盖**，见 G3=0%）

**结论**：rubric 的"边界标注"是**方法论自认**——诚实声明"我们的方法在 roughness>0.3 的场景上不适用"，但这**不意味着**"这些场景可以泛化到设计域外"。

## 四、是否需要把外推能力纳入 rubric？

**否**。三条理由：

1. **违反 A15**：外推能力在当前架构下**结构性不可达**（GP 核函数性质），纳入 rubric 会让所有场景都失败，rubric 变得没有区分度
2. **量纲问题无解**：G3 需要跨学科对齐，这不是"增加 rubric 项"能解决的
3. **rubric 定位不同**：rubric 是"方法是否在该设计域内有效"，不是"方法能否外推"

**替代方案**：保留 rubric 的当前边界标注，另用 `generalization_bench` 独立报告外推/G3 数据。两套系统互补、不冲突。

## 五、对核心目标的含义

核心目标要求"跨学科问题 ≤20 次虚拟实验内给出带校准区间的结论"。基于 G3=0%：

- **当前架构无法支撑跨学科外推**，只能在设计域内插值
- **跨学科问题必须逐学科重新校准**，不能复用单学科模型
- **适用域边界**（A14）与**外推边界**（A15/G3）必须同时向用户声明

## 附录：判据

- **A14 判据**：`roughness = mean(|Δ²f|) / std(f) > 0.3` → 超出平滑代理模型适用域
- **G3 判据**：单学科独立训练 → 预测其他 13 学科测试集 → `mean rel <= 0.3` 才算泛化成功
