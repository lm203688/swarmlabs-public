## A. 注册有限责任公司（所有 T2 投资渠道的总闸门）

**为什么是阻塞**：投资人/收购方尽调第一条就是"有没有法律实体"。目前项目是个人仓库 + 无公司，等于没有签约主体——这是当前最大的可发现性之外的硬伤。

**最简路径（中国大陆，科技类小规模纳税人）**
1. 核名：当地"政务服务网"或"市场监管局"一网通办 → 企业名称自主申报（建议名：`杭州/深圳/你所在地面 + 思沃姆 / SwarmLabs 相关字号 + 科技/智能 有限公司`）。
2. 注册资本：认缴制，建议 10–100 万人民币（无需实缴），别写太高。
3. 经营范围（参考填）：`技术服务、技术开发、技术咨询；人工智能基础软件开发；人工智能应用软件开发；实验分析仪器销售；自然科学研究和试验发展`。
4. 材料：法人/股东身份证、注册地址（可用托管地址，约 1–3k/年）、公司章程（系统自动生成）。
5. 刻章 + 银行对公户 + 税务报道（全线上，约 3–7 个工作日）。

**入口（按你所在地选）**
- 浙江/杭州：`https://www.zjzwfw.gov.cn`（亲清在线 / 企业开办一网通办）
- 深圳：`https://amr.sz.gov.cn`（秒批试点，最快）
- 通用：国家企业信用信息公示系统 `https://www.gsxt.gov.cn`

**草稿：公司章程关键条款（待你填）**
- 公司名称：________
- 注册资本：____ 万元（认缴）
- 法人/股东：厉兴（你），占股 ____%
- 主营业务：AI for Science 科研实验虚拟验证 + 不确定性量化

## B. 算力券 / 政府算力补贴（降本 + 政府背书，投资人爱看）

**为什么有价值**：① 直接降 GPU/CPU 推理成本（当前跑在 GMKtec NucBox + 腾讯云 ECS）；② "入选 XX 算力补贴"是强背书，写进投资人页。

**可申报入口（零/低成本优先）**
1. **智算中心算力券**（多地政府发）：如"杭州算力券""深圳算力券"——搜索你所在地面 + "算力券 申报"。
2. **阿里云 / 腾讯云 初创企业扶持**：
   - 阿里云"创业中心 / 云启": `https://www.aliyun.com/activity/startup` → 免费云资源额度
