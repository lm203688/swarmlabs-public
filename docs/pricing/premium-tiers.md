# SwarmLabs 定价分层方案（猫眼 P1 · premium 档探索）

> 依据：`docs/competitive/maoyan-ketibo-analysis.md`。结论：猫眼课题宝证明「科研工具」市场有强付费意愿（选题 99–199/次、标书 299/份、月卡 799、年卡 3899），且企业/研究院是高客单价场景。SwarmLabs 当前 license 仅 ¥39.9 / ¥199，显著低于该水位，存在上探空间。

## 1. 错位定位（先讲清不竞争）

| 维度 | 猫眼课题宝 | SwarmLabs |
|---|---|---|
| 干什么 | AI 写选题 / 写标书（文本/知识层） | 用虚拟实验**验证**技术路线可行性（仿真/验证层） |
| 输出 | 文本草稿（自陈「建议结合前期研究修改」） | 误差棒 + 95%CI 覆盖率 + OOD 红区（可溯源证据） |
| 关系 | — | **写 → 验** 真实组合：标书写完，用 SwarmLabs 验可行性再提交 |

我们不替代猫眼，而是补上它明确缺的「验证」一环，并借其 20 万科研用户心智做 GEO 引流。

## 2. 建议分层

| 档位 | 价格（建议） | 包含 | 目标用户 |
|---|---|---|---|
| **Free / 试用** | ¥0 | 2 个场景、基础 GP surrogate、覆盖率报告 | 学生 / 评测期用户 |
| **Pro**（现有） | ¥39.9 / 月 或 ¥199 终身 | 全场景 GP+FNO 双后端、UQ 门禁、仪表盘 | 个人研究者 |
| **Premium · 标书可行性验证** | **¥999 / 年** | Pro 全部 + **N=12 次虚拟实验验证报告**（可贴进标书「可行性 / 风险与应对」章节）+ 课题申报验证层话术模板 | 课题组 / 需频繁申报者 |
| **Team / 机构版** | **¥4,999 起 / 年（5 席位）** | Premium 全部 + 私有化部署选项 + 多用户协作 + 优先算力（远程推理后端） | 企业科研部 / 研究院 / 高校平台 |

## 3. 关键判断（不夸大）

- **上探有理**：猫眼年卡 3899 已被市场验证，Premium ¥999 属「专业工具合理水位」，远低于猫眼且不抢其客群。
- **机构版是高客单价杠杆**：对标猫眼企业场景，席位制 + 私有化可显著拉升 ARPU；ISO 27001/27701 是 enterprise 入场券，我们暂无——但 **UQ 可溯源本身即信任资产**，可先讲「验证可信」再补合规。
- **不堆参数军备**：定价锚定「验证可信度」而非「模型规模」，与 AU 式叙事切割，延续我们的纪律。
- **风险**：若鲸灵 AI（猫眼背后）延伸到虚拟实验会成直接竞品——先占位「验证主导 + UQ」定位。
