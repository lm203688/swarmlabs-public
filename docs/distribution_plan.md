# SwarmLabs 分发渠道筹划（含大厂资源嫁接）

> 状态：筹划 v1（2026-08-14），渠道口径 2026-10-08 更新。所有"大厂"条目均为「生态入口」，非已签约分发，勿写进材料当事实。

## 0. 核心定位
- 我们卖的不是模型，是「验证主导 + UQ + 主动学习挑最该做的真实实验」闭环服务。
- 分发目标：让真实研究者（发酵 / 合成生物 / 生物工艺优先）**免注册试用 → 提供真实数据 → 我们回建议 → 收集真实需求**。
- 当前唯一真实渠道：Cloudflare 自有站 `swarmlabs.tools`。真实外部用户 ≈ 0，首要 KPI = 拿到第一个真实实验数据集（不是下载量 / star 数）。

## 1. 渠道分层

### A. 自有渠道（已建，待充实）
- `swarmlabs.tools`（Cloudflare）：把发酵试用页按 Evo Designer 风格做成真网页，无登录墙。
- MIT 开源 repo `swarmlabs-engine-kit`：GitHub 全球分发基础。
- 动作：试用页上线 + README 引流。

### B. 大厂资源嫁接（生态入口，低摩擦）
- **阿里云（生态入口）**：AgentTeams 平台有可运行的多智能体编排样板，可作为技术集成/合作样板（非已签约分发）。以"可信验证层"能力切入阿里云 AI 生态。
- **华为昇腾（潜在）**：算子级适配验证 + 杭州智算中心 / 昇腾生态创新中心触点，标注「规划中」，非已签约分发。
- **百度飞桨（已跑通）**：PINN+UQ Notebook 本地 coverage 0.955，发布到飞桨星河社区 / AI Studio → 触达中文 AI 开发者。素材现成。
- **NVIDIA（远期对标）**：对标 Evo 的 BioNeMo / NIM，现体量不够，列为远期，不投入。

### C. 全球开源 + 学术（最高杠杆、免费）
- **Hugging Face**：发布 GP surrogate / 微生物场景 demo space。
- **arXiv**：发短技术报告（Virtual experiment with UQ parity），对标 Evo 的 Nature 公关效应，建可信度。
- **学术网络**：用户 = 教授级高工 + 乌克兰工程院外籍院士，定向邮件给同行（发酵 / 合成生物）是最高转化冷启动渠道。

### D. 社区 + 内容（GEO 已定）
- **GEO 自治闭环**：不投 HN，走生成式引擎优化（既定）。
- **中文社群**：生辉科技、小木虫发酵版、知乎相关话题。

## 2. 优先级与节奏
- **P0（本月，确定性高）**：① 发酵试用页上线；② 阿里云 AgentTeams 技术集成样板（生态入口）；③ GitHub / HF 开源发布。
- **P1（次月）**：④ 飞桨星河发布 PINN demo；⑤ 学术邮件定向邀请；⑥ arXiv 技术报告。
- **P2（待条件）**：⑦ 华为昇腾编译上榜 → 接入智算中心（需你上云 + 时间）。
