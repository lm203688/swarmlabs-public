## 0. 结论先行

**① 技术位置：真实占据、结构性稀缺、且可被第三方当场证伪。**
我们做的是 AI4S 的**裁决层**（fail-closed 验证闸门 + 诚实不确定度）。这不是自我包装，是竞品**公开放弃**后留出的空位——SciencePro 官方口径「最终评价与研究决策仍由科研人员和评审专家负责」（= 只给建议，不做门禁）；OpenResearch 两条支线只做**谱系**（这个数字出自哪个代码状态），不做**裁决**（这个声明在给定不确定度下是否可信）。

**② 市场位置：一个真空位，而不是一个已占领的阵地——包括我们自己也没占。**
因为市场**不知道这个位置存在**。硬事实：GitHub stars=0、无公司实体、pre-revenue、bus factor=1、门禁的外部消费者=0。真空位有双重解释：既是机会，也可能是「这个需求根本不存在」的证据。**目前无法区分这两者**，唯一能区分它的动作是让某个真实机构真用一次（见 §6 第 6 条）。

**③ 下一阶段方向：不是「让更多人相信我们可信」，而是「让替代在更多真实场景下站得住且可被独立复验」。**
市场谋划的全部合法性来自这一条：**先有可归档、可独立复验的裁决产物，再谈谁来引用它。** 反过来做（先做曝光/叙事/分发）在 09-19 已被逐条判为偏出，本文不重犯。

## 1. 位置判断：把「市场位置」拆成三个可分别取证的层

一个笼统的「我们在市场上什么位置」无法取证。拆三层，每层给取证方式与评级。

| 层 | 我们当前的坐标 | 取证方式 | 评级 |
|---|---|---|---|
| **技术位置** | AI4S 的**裁决层**（对 agent 说 no 的那一层） | 复跑门禁 + 读归档包 + 当场注入篡改 | **真实且稀缺** |

| **商业位置** | 接近零；To C 路径已被免费层击穿 | license 转化数据 | **负** |

`engine-kit/skills/vv-gate/`（零依赖 CLI，退出码 0/3/2/1）、`engine-kit/vv_gate_server.py`（零依赖 stdio MCP，6 工具）、`POST /v3/verify` + `GET /v3/openapi`、`packages/sciencehub-skill/verify-scientific-claim/` —— **四件可分发物全部真实可跑**（`selftest 9/9`）。但 stars=0、外部消费者=0。

## 3. 唯一的结构性位置：裁决层

### 3.1 为什么对手不来抢（机制论证，不是情绪）

| 对手 | 它做的是什么 | 为什么不做裁决 |
|---|---|---|
| SciencePro | 建议（多智能体出结构化报告） | 卖能力的平台不能同时当裁判。说「不许执行」就要为错杀负责。官方明文交回人类。它自述创新评价「与专家结论匹配度 80% 以上」→ **它自己承认有 ~20% 不确定区**，那 20% 就是需要独立门禁的全部理由 |
| Google Co-Scientist / AlphaEvolve | 生成假设 + idea tournament（Elo 排名） | 编排层自身承担「跑通多少」的 KPI；阻断 = 伤害自身指标 |
| OpenResearch（alphaXiv A / openResearch1 B） | 谱系：这个数字出自哪个 commit | 可复现 ≠ 有效。**一个完全可复现的实验可以完全错误** |
| 智谱 / Claude for Science | 读 / 写 / 综述科研（知识加工） | 不同任务，不触及数值级 UQ |
| 猫眼课题宝 等中文课题平台 | 选题 / 申报辅助 | 应用层，无门禁 |

**机制级的护城河不是「我们做得更好」，而是「没人愿意做同一个动作」**——因为做了要为自己的否决心负责。这跟 09-19 教训一致：「判竞品不能只比谁更强，必须比**谁会做我不会做的动作**」。

### 3.2 谁为「否决权」付钱

| 买方画像 | 痛点 | 我方对应产物 | 现实性 |
|---|---|---|---|
| 湿实验成本高且不可逆的研发组织 | 一次错误实验 = 数周到数月 + 物料不可回收 | 门禁 BLOCK / HUMAN_CHECK + 干预前的证据链 | 高 |
| 需要审计留痕的受监管场景 | 谁批准了方案、依据是什么 | V&V 归档包（篡改可捕获）+ 账本 provenance | 中（合规周期长） |
| 需要给 agent 加「能说不」的下游 | 自主 agent 会 plausible-but-wrong | 零依赖 MCP gate + HTTP 端点 | **中——但需先证明有买方** |
| 个人研究者 | 免费层已覆盖 | — | **低，放弃** |

### 3.3 这个位置的天花板（诚实）

1. **市场可能不存在。**「对 agent 说不」听起来正确，但买方是否为它单独付钱，我们没有一条证据。
2. **单点依赖。** bus factor = 1，无公司实体，pre-revenue，GH stars = 0——这三条是项目自己的**总闸门**，不因技术位置好而消失。
3. **技术优势窗口不是永久的。** ECE 0.0083 与 fail-closed 都不是专利；一旦某家把「验证层」当战略基础设施（UniPat 估值 $25 亿、Anthropic $4 亿收购 Coefficient Bio 已确立这个范式），追赶成本对它们很低，对我们很高。
4. **裁决层的收入天花板低于平台层。** 卖能力可以按席位/按量规模化；卖否决权是低频、高信任成本、需要合规背书的生意。

**所以这个位置的正确用法是「稀缺 + 可验证」，不是「大市场」。** 把它当护城河讲可以，把它当增长故事讲会露馅。

## 5. 市场谋划

### 5.1 客户重新定义

从「科研人员个人」转向「**错误实验成本高、且需要留痕的组织**」（§3.2）。这个转向的直接后果：
- 产品语言从「更好的预测」→「**在证据不足时禁止执行**」；
- 定价从席位/月费 → **按裁决次数计量**或**机构授权 + 审计留痕**；
- 交付物从「报告」→「**可归档 V&V 包 + 门禁决策日志**」。

### 5.2 渠道：GEO 是产物的副产品，不是营销动作

这是本文与常规「市场谋划」最大的不同，也是必须坚持的纪律：

- **不做**：为 SEO 而写内容、追热点、投放、蹭竞品关键词。
- **做**：**每一条对外可见的资产都必须由一个可复验产物派生**——报告库条目、阶段锚点、门禁账本、锚点表。内容只是产物的**投影**，不是独立营销物料。

现状：sitemap 70 URL、14/14 文章、12 篇 GEO 博客。**问题不是数量不够，是没有一条可归因转化。** 因此在有第一个真实消费者之前，**GEO 不加量，只保证「已发布内容与产物口径一致」**（本轮已由 `check_public_numbers.py` + `lint_frontend_i18n.py` 变成 CI 硬门禁，债只能降不能升）。

## 8. 战略转向：纯技术做到极致 → 资本引入（2026-09-21 用户定调）

用户原话：「这个项目可能后面是纯技术方向了，要把技术做到极致，然后通过投资引入资源。」

这一定调与本文结论**同向但不等同**，需拆清两层，否则容易滑回 09-09 已判 ❌ 的动作：

**一致的部分（照做）**
- 「纯技术做到极致」= 继续投 09-09 判据下的核心真源（替身质量 / 裁决可靠性 / 可独立复验）。本轮回填的两件 P0（篡改可捕获的归档包、前端公开诚实失败）正是这一方向的硬资产。
- 它同时**坐实**了 90 天清单的「不做」三项：平台曝光竞品叙事 / 实体库数量竞赛 / 融资外联——纯技术路线下这些本就不该占团队工时。

**必须校准的部分（防误导）**
- 「通过投资引入资源」是**结果 / 时点**，不是**日常工作**。09-09 把「投资人 / 合作方外联」列为 ❌ 判例，判的是「把外联当替代核心产品推进」这种动作，不是禁止未来融资。正确解读：让技术资产硬到**资本主动来**，而不是分心去做路演 / 商业计划书式的外联。两者根因相同——都是「用『如何让人相信』框架思考，而非『如何让虚拟实验本身更可替代』」。
- **极端技术不等于市场成立**。本文 §5 已证：市场位置仍是空的（stars 0、外部消费者 0）。技术做到极致只能把「被投资的价值」做厚，不能替「第 6 条：让一个真实外部系统调用一次门禁」证伪市场存在。资本会问的第一个问题就是「有人在用吗」——答案仍依赖那一次真实调用，而非更多技术。
- 因此下一阶段的**唯一对外 KPI 仍是 #6**（真实外部门禁调用）；技术投入的验收标准仍是「更可替代 / 更可复验」，二者不互相替代。

**对投资叙事的含义（给未来用，现在不做）**
- 可对外讲的技术资产已齐：82 场景 V&V、ECE 0.0083、fail-closed 门禁族、篡改可捕获的归档包、公开承认外推 73/82 失效的诚实边界。这些构成「AI4S 裁决层」的 defendable thesis。
- 现在**不**启动：investor deck / 路演 / 融资外联。等 #6 有真实调用记录后，这些才是顺理成章的下一步。

---

> **一句话给用户**：技术位置是真的（82 场景 / ECE 0.0083 / fail-closed 门禁 / 篡改可捕获的归档包，全部可当场复跑），
> 市场位置是空的（stars 0、外部消费者 0），商业位置接近零（免费层已击穿 To C）。
> 下一阶段的正确方向不是把「可信」讲给更多人听，而是**让替代在更多真实场景站得住、且让任何第三方在无网络无设备下都能独立复验**；
> 90 天内唯一能证伪「这个位置有没有市场」的动作，是**第 6 条：让一个真实外部系统调用一次门禁**。
