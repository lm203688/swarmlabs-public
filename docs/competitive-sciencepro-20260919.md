# 磐石 SciencePro 对 SwarmLabs 的影响评估

评估日期：2026-09-19 ｜ 事实核查完成，全部结论带来源锚点

---

## 0. 一句话结论

**SciencePro 在"平台广度"这条赛道上我们已经赢不了了，但它明确公开放弃了另一样东西——否决权。**
我们全部的生路就在这个空隙里；其余方向（数据量、工具生态、C 端订阅）应当主动收缩，不要再投。

## 2. 正面撞车的三件事（先说坏消息）

### 2.1 数据量差距是 3 个数量级，不是"再补一补"能追的

| | SciencePro | SwarmLabs | 倍数 |
|---|---|---|---|
| 论文/专利 | 2.7 亿 | — | — |
| 科研项目 | 3200 万 | — | — |
| 结构化实体 | （平台级） | **47,566** | **≈ 5700×** |
| 工具/数据库 | 2000+ 工具 / 300+ 库 | 62 场景引擎 | ~30× |
| Skills | **7000+** | 少量 | 数量级 |

**结论**：任何"我们数据也在增长""我们目标 100k 实体"的叙事，在这个对手面前都不成立。
47,566 → 100k 是 2 倍；对方是 5700 倍。**这条线不要再投。**

### 2.2 "创新评价"这个叙事被抢了先手，而且是国家队 + 上市公司

我们此前设想过把验证闸门包装成"前置评价"。SciencePro 已经用"业界首个创新评价"
把它占了，并且带着中科院背书和 190 亿港元市值发布。**同一句话我们再说一遍，只会显得是跟随者。**

### 2.3 To C 订阅这条路基本被堵死

SciencePro **有免费版**，且"免费版覆盖日常科研需求"。我方 license 定价 Pro ¥39.9 / 终身 ¥199
（另有一套 ¥199 月 / ¥999 终身的 plans API）。
**在"免费 + 国家队 + 手机号即用"面前，¥39.9 的说服力接近于零。**
这不是定价问题，是信任成本问题——用户没有理由为一个无背书的小站付钱买它本可以免费拿到的能力。

> 这一条对 license.swarmlabs.tools 的商业化计划是**实质性打击**，需要重新做决策。

## 3. 它的结构性空洞（我们的位置在这里）

官方新闻稿里有一句关键的话，反复出现在所有版本：

> "**最终评价与研究决策仍由科研人员和评审专家负责。**"

这句话是它的**商业模式决定的**：平台方卖的是"能力"，卖能力的人不能同时当裁判。
如果 SciencePro 说"这个方案不行，不许执行"，它就要为错杀负责——它不愿意，也不能。

**所以它做的是"建议"，不是"门禁"。它能给出结构化报告，但它不能对 agent 说 no。**

我方 `engine/verification_gate.py` 的 `assert_action_allowed` 是 **fail-closed** 的——
够不到证据就拒绝放行，而不是"够不到就当通过"。这是我方唯一结构性的、对方不会来抢的位置。

## 4. 三个真正的差异点（不是安慰，是能验的）

| 差异点 | SciencePro | SwarmLabs | 是否可验 |
|---|---|---|---|
| **UQ 一等公民** | 全部材料**零提不确定度**（只谈数据量、盲测超越） | 噪声地板 3% 不降、覆盖率 ≈0.95、V&V PASS = R²≥0.90 **且** cov≥0.90 单侧下界 | ✅ 可复跑 |
| **双证据链不互相掩盖** | 宣称"过程可追溯、可返回原文核验" | `wet_lab_anchors.py` 6 锚点四档（AGREE/NEAR/CONTRADICTED/UNANCHORED），`chains_agree` **可以显式返回 false** 并保留 5 条 REFUTED 硬阻断 | ✅ 已实测 |
| **能否决** | **不做**（明确交回人类） | `assert_action_allowed` fail-closed | ✅ 可测 |

**第二条尤其重要**：SciencePro 的"可追溯"是**单向增强**——它只会让结论看起来更可信。
我们的设计是**允许两条证据链公开打架**（`GET /v3/anchors/microbio_monod` 就返回
`wet_lab{CONTRADICTED, Ks 偏离 44×}` vs `vv_gate{PASS, r2: 0.9997}`，`chains_agree: false`）。
一个愿意公开自己两条链不一致的系统，比一个只会说"我可追溯"的系统更值得信。

**这三条合起来才是"可信验证层"。对方一条都没做，因为做了会伤害它的销售话术。**

## 5. 可借鉴的 6 件事（按性价比排序）

| 优先级 | 借鉴项 | 具体动作 | 成本 |
|---|---|---|---|
| **P0** | **Projects 课题容器** | 以"课题"为单位归档：场景配置 + gate ledger + 双证据链快照 + 报告。对外叫"可归档 V&V 包"。我们有 reports/ 和 ledger，缺一层容器 | 低 |
| **P0** | **Skill 自带证据** | 把 62 场景 + gate 封装成可上传/评分的 Skill 模块。**不追数量，追"每个 Skill 自带 V&V 证据 + UQ"**——这是对方 7000 个 Skill 全都没有的属性 | 中 |
| **P1** | **本地化部署做成独立卖点** | 对方本地化要交付大模型权重（重、贵、要算力）。我们**纯 numpy、零外部依赖、单机可跑、可 air-gap**。这是成本结构上的真实优势，要在官网明写 | 低 |
| **P1** | **一个可证伪的招牌案例** | 对方招牌是"+38% / 数月→30分钟"。我们的招牌应该是**相反的**：一个被我们 CONTRADICTED 掉的方案（Ks 偏离 44×）。"我们敢说这个方向不成立"比"我们提升了 38%"更稀缺 | 中 |
| **P2** | **评价前置的产品语言** | 借它已教育出的市场（"评价应该前置"），但必须紧跟一句区分：**它是提前给建议，我们是提前给否决** | 低 |
| **P2** | **科研头条式订阅推送** | 我们有 GEO 博客 + 47,566 实体，可做轻量领域订阅。但这不是主线，别投入过多 | 低 |

## 6. 必须立刻改的三件事

### 6.1 竞品清单要更新，SciencePro 应列为**最高危险级**

此前清单是 Google Co-Scientist / Claude for Science / A-Lab。SciencePro 比它们都危险：
**本土 + 国家队背书 + 已上市有钱 + 免费开放 + 中文场景贴合**。海外竞品够不到中国科研用户的日常，
它够得到。

### 6.2 所有申报/路演口径，禁止出现这三个词

**"创新评价"、"智能体广场"、"科研 Skill 社区"**——
评委看到就会直接对标中科闻歌，且我们是明显的弱侧。

**换成**：`AI4S 实验替代的可信性验证` / `fail-closed 执行门禁` / `诚实不确定度量化` / `双证据链仲裁`。
先说"我们能对 AI agent 说不"，再说别的。

### 6.3 To C 订阅要降级，重心转向"机构/受监管场景"

理由见 2.3。真正需要"否决权 + 不确定度"的，不是个人研究者，而是：
- 需要**审计留痕**的机构研发（谁批准了这个方案、依据是什么）
- 需要**避免错误实验成本**的场景（湿实验贵、不可逆）
- 需要**合规证据链**的场景

**这类客户才可能为"可信"付钱，而不是为"能力"付钱——能力他们已经能白拿了。**

## 7. 不要做的事

1. ❌ 不要扩大实体数据集去比数量（5700 倍差距，无底洞）
2. ❌ 不要去建工具/数据库集成生态（对方 2000+，我们几十）
3. ❌ 不要把"我们也有智能体"当卖点（对方 13 个已包装成三档产品）
4. ❌ 不要跟"创新评价"这个词（先手已丢）
5. ❌ 不要指望 Skill 大赛（09-17 已截止）
6. ❌ 不要为了追进度牺牲 UQ 诚实性——**那是我们唯一的护城河，丢了就什么都不剩**
