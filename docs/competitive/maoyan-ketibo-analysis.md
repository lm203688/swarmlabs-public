# 猫眼课题宝（myketi.com）对 SwarmLabs 的提升与帮助 — 深度分析

> 分析日期：2026-08-30 ｜ 对象：猫眼课题宝（见鲸科技，鲸灵AI 科研垂直大模型）
> 立场：客观、证据优先、不夸大。猫眼是第三方付费 SaaS，所有"帮助"来自流量心智 / 产品定位 / 市场验证 / 公开趋势监测，而非嵌入其私有数据。

---

## 1. 猫眼课题宝是什么（事实锚定，来源官网 myketi.com 及多家导航站）

- **出品方**：见鲸科技；自研 **"鲸灵AI" 科研垂直大模型**（基于 879 万+基金 + 1.8 亿+文献垂直训练，覆盖 8 大学部 1270+ 领域、117 个一级学科、28 万+专业双语词）。
- **数据**：80 万+ 国自然基金、799 万+ 海外基金、1.8 亿+ 前沿文献、40 万+ 结题报告。
- **核心功能**：① 5 分钟定创新选题；② 3 步出标书（覆盖面上/青年/地区/省市级，约 90% 框架）；③ 全球基金查询；④ AI 文献分析（自动提炼综述、识别研究局限性/空白点）；⑤ 选题热点订阅。
- **用户与场景**：累计 20 万+ 用户；高校教研组 / 医院课题组 / 研究院 / 企业科研部 / 硕博。
- **合规**：ISO/IEC 27001:2022 + ISO/IEC 27701:2019（信息安全 + 隐私）。
- **定价**：选题 99–199 元/次、标书 299 元/份、月卡 799（10 次选题）、年卡 3899（不限次）。PC + App 双端。
- **定位**：**科研选题与标书生成 SaaS（文本/知识层）**——帮人"写得更快"，不碰仿真/验证。

---

## 2. 与 SwarmLabs 的关系：互补而非竞争

| 科研工作流 | 猫眼课题宝 | SwarmLabs |
|---|---|---|
| 定选题 | ✅ 5 分钟定题 | （可验证选题假设） |
| 写标书 | ✅ 3 步出标书框架 | （可验证技术路线可行性） |
| **可行性验证** | ❌ 不碰 | ✅ 虚拟实验替代真实实验、UQ、误差棒、OOD 门禁 |
| 执行/真实实验 | ❌ | 仿真→真实校准（mirror run） |

猫眼覆盖"选题 → 写标书"两段，我们覆盖"可行性验证"这段。二者在流水线上**相邻不重叠**：猫眼生成标书，评审最爱质疑的"可行性/风险与应对"恰是 SwarmLabs 的补位。

---

## 3. 对 SwarmLabs 的提升与帮助（分维度）

### 3.1 流量 / GEO 渠道（最高杠杆，零成本）
- 猫眼有 **20 万+ 科研用户**（高校/医院/研究院/企业科研部/硕博）——正是 SwarmLabs 目标受众。
- 它占住了"课题选题/标书 AI"搜索心智（百度搜"猫眼课题宝"直达）。SwarmLabs 可**错位竞争**：写"标书可行性验证 / 用虚拟实验支撑技术路线"类 GEO 内容，捕获同一批人而不正面撞关键词。
- 落地：已写 GEO 博客 `frontend_fixed/blog/grant-proposal-validation.html`，把 SwarmLabs 定位为"标书写完后的验证层"。

### 3.2 产品互补 → 新定位 / 卖点
- 标书评审高频质疑："可行性不足""风险与应对空"。SwarmLabs 的虚拟实验输出（误差棒、覆盖率、OOD 红区）可直接喂进标书**「可行性」与「风险与应对」**章节，形成 **"AI 写标书 + AI 验证可行性"** 的真实组合叙事（非编造）。
- 可做 landing 话术："SwarmLabs × 课题申报：用虚拟实验验证你的技术路线，提升中标率"。纯定位/文案成本，零代码。

### 3.3 数据飞轮 enrichment（OSINT，合规边界内）
- 猫眼的"研究空白点/局限性识别"、基金立项趋势、结题报告库，是科研趋势/研究空白的现成情报源。
- 我们已有 **47k 结构化实体**（趋势/研究空白/跨域桥接/合著网络）。可把猫眼**公开免费页**（基金查询、热点趋势）作为监测源，补充"研究空白/趋势"实体。
- **边界**：仅用其公开免费部分；不破付费墙、遵守其 ToS；不抓取私有数据。

### 3.4 商业化 / 定价借鉴
- 猫眼证明"科研工具"市场有强付费意愿（年卡 3899）。我们 license 仅 ¥39.9 / ¥199，远低于该市场水位。
- 启示：① 可上探价格或加 **"标书可行性验证"premium 档**（如 ¥999/年含 N 次虚拟实验验证报告）；② 企业科研部/研究院客单价更高，可推团队/机构版（对标猫眼企业场景）；③ ISO 27001/27701 是 enterprise 入场券——我们暂无，但 **UQ 可溯源本身是信任资产**，可先讲"验证可信"再补合规。

### 3.5 竞争边界与风险
- 猫眼当前是文本层，不碰仿真/验证，**短期不竞争**。
- **风险**：若"鲸灵AI"延伸到"实验设计/虚拟实验"，会成为直接竞品（其有垂直 LLM + 文献/基金数据，"写标书 + 设计实验"顺理成章）。
- **应对**：守住"验证主导 + UQ 一等公民 + 仿真→真实校准"硬差异，轻量自治（日级运行），抢先占位"可行性验证"心智，不被其文本叙事带偏。

## 4. 客观判断（不夸大）

- 猫眼是第三方付费 SaaS，我们**不能嵌入、无法集成其私有数据**。所有"帮助"来自：借其流量心智做 GEO、借其暴露的科研需求做产品定位、借其定价验证市场、借其公开页做趋势监测。
- 不要神化：猫眼自陈"标书不能直接套用，建议结合前期研究修改"——它深知自己是"辅助"不是"替代"。我们同理——虚拟实验是"对等验证"不是"替代真实实验"。**定位诚实一致**。
